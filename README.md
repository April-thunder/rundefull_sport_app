# RUNDEFULL — беговой трекер

Приложение на React для учёта тренировок, отслеживания ресурса обуви и анализа беговой статистики.

## Реализованный функционал

### Тренировки
- Добавление, редактирование, удаление тренировок (CRUD)
- Пагинация списка (по 3 тренировки на страницу)
- **Детальное окно тренировки**:
  - Отображает дату, дистанцию, время, темп, самочувствие, обувь, средний и максимальный пульс (заглушки)
  - Карта маршрута и графики темпа/пульса (заглушки, можно заменить реальными)
  - Кнопки «Редактировать» и «Удалить» перенесены в это окно
- Клик по тренировке в списке открывает детальное окно (убраны иконки редактирования/удаления из списка)
- **Сортировка** – тренировки отображаются от новых к старым (самые новые на первой странице)
- **Единый формат дат** – все даты хранятся в ISO (`YYYY-MM-DD`), при отображении преобразуются в читаемый вид (например, «16 апр 2025»). Старые данные мигрируются автоматически.

### Обувь
- Отображение списка «Моя обувь» с динамической загрузкой из `localStorage`
- **Добавление новой обуви** через модальное окно:
  - Выбор фирмы (Nike, Adidas, Asics, Saucony, Hoka)
  - Выбор модели из 10 предустановленных или ручной ввод
  - Указание максимального пробега (км)
  - Автоматическая подстановка картинки по пути `/shoes/бренд-модель.webp` (файлы хранятся в `public/shoes/`)
  - Заглушка «Изображение добавлю позже» при отсутствии картинки
- **Индикатор ресурса** для каждой пары обуви:
  - Зелёный: израсходовано <60% ресурса
  - Жёлтый: 60–90%
  - Красный: ≥90%
- Пробег обуви обновляется автоматически при добавлении, редактировании и удалении тренировок (миграция старых данных выполнена)

### Статистика и аналитика
- **Страница статистики** (`/statistics`) с полноценными графиками:
  - График объёма (столбцы) – группировка по годам, месяцам, неделям, дням
  - График среднего темпа (линия) – с теми же периодами
  - Круговая диаграмма распределения тренировок по дистанциям
  - Круговая диаграмма пробега по обуви
- Карточки с ключевыми метриками: общий пробег, количество тренировок, средний темп, средняя дистанция
- **Фильтрация статистики по периодам** на главной странице (`StatsPanel`):
  - Выбор периода: Неделя, Месяц, Год, Всё время
  - Количество тренировок и дистанция обновляются в соответствии с выбранным периодом
- На главной странице отображаются **рекорды** (10 км, полумарафон, марафон) – пока статические, но могут быть вычислены из тренировок в будущем.

### Управление состоянием (Context API + кастомный хук)
- **Глобальное состояние** вынесено в `AppContext` (отдельный файл контекста и хук `useApp`):
  - Доступ к массивам тренировок (`workouts`), обуви (`shoes`), данным пользователя (`user`)
  - Функции CRUD: `addWorkout`, `updateWorkout`, `deleteWorkout`, `addShoe`, `updateUser`
  - Период фильтрации статистики (`period`) и функция `filterByPeriod` (поддерживает «Всё время»)
- Контекст оборачивает всё приложение в `main.jsx`, данные доступны на любой странице без проброса пропсов.
- Кастомный хук `useApp` импортируется в компонентах для получения данных и функций.

### Интерфейс и навигация
- **Многостраничная навигация** с помощью `react-router-dom`:
  - Главная (`/`) – трекер тренировок и обуви
  - Статистика (`/statistics`) – страница с графиками и аналитикой
  - Профиль (`/profile`) – страница профиля (в разработке)
- Кнопка «+» рядом с заголовками «Тренировки», «Моя обувь», «Ближайшее соревнование» (добавление тренировки / обуви / соревнования)
- Убрана большая кнопка «Добавить тренировку» – заменена на компактный плюс
- Адаптивный дизайн, сине-серебристая гамма
- Сохранение данных в `localStorage` (тренировки, обувь, пользователь)
- **Компактные отступы** для оптимального использования экранного пространства

### Прочее
- Блок «Рекомендуемая обувь» – статический, с карточками и ссылками на магазины
- Соревнования – пока только статический пример (Московский марафон), планируется CRUD

## Стек технологий
- React (функциональные компоненты, хуки `useState`, `useEffect`, `createContext`, `useContext`)
- React Router v6 (маршрутизация)
- Vite (сборка)
- CSS (единый файл `App.css`, стили группированы по компонентам)
- **recharts** – для построения графиков на странице статистики
- ESLint – линтинг кода

## Данные
- **Тренировки** хранятся в `localStorage` под ключом `rundefull_workouts`
- **Обувь** – `rundefull_shoes`
- **Пользователь** – `rundefull_user`
- Начальные данные импортируются из `src/data/initialData.js`
- Даты автоматически мигрируются из старого формата (русские названия месяцев) в ISO при первом запуске.

## Что не реализовано (планы)
- **Расчёт рекордов из тренировок** – сейчас статические значения, планируется автоматическое вычисление лучших результатов.
- **Настоящие карты и графики** – сейчас используются изображения-заглушки.
- **Уведомления о превышении ресурса обуви** – планируется оповещение при достижении 90% износа.
- **Страница профиля** – пока заглушка, планируется редактирование данных пользователя (имя, возраст, вес, фото, пульс и т.д.).
- **CRUD для соревнований** – сейчас только статический пример.
- **Импорт/экспорт данных** (например, CSV).
- **Переход на клиент-серверную архитектуру** – замена `localStorage` на API (планируется).
