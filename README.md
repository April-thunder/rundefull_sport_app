# RUNDEFULL — беговой трекер

Приложение на React для учёта тренировок, отслеживания ресурса обуви и планирования соревнований.

## Реализованный функционал

### Тренировки
- Добавление, редактирование, удаление тренировок (CRUD)
- Пагинация списка (по 3 тренировки на страницу)
- **Детальное окно тренировки**:
  - Отображает дату, дистанцию, время, темп, самочувствие, обувь, средний и максимальный пульс (заглушки)
  - Карта маршрута и графики темпа/пульса (заглушки, можно заменить реальными)
  - Кнопки «Редактировать» и «Удалить» перенесены в это окно
- Клик по тренировке в списке открывает детальное окно (убраны иконки редактирования/удаления из списка)

### Обувь
- Отображение списка «Моя обувь» с динамической загрузкой из `localStorage`
- **Добавление новой обуви** через модальное окно:
  - Выбор фирмы (Nike, Adidas, Asics, Saucony, Hoka)
  - Выбор модели из 10 предустановленных или ручной ввод
  - Указание максимального пробега (км)
  - Автоматическая подстановка картинки по пути `/shoes/бренд-модель.webp` (файлы хранятся в `public/shoes/`)
  - Заглушка «Изображение добавлю позже» при отсутствии картинки
- **Индикатор ресурса** для каждой пары обуви:
  - Зелёный: израсходовано <60% ресурса
  - Жёлтый: 60–90%
  - Красный: ≥90%
- Пробег обуви обновляется автоматически при добавлении, редактировании и удалении тренировок (миграция старых данных выполнена)

### Управление состоянием (Context API)
- **Глобальное состояние** вынесено в `AppContext`:
  - Доступ к массивам тренировок (`workouts`), обуви (`shoes`), данным пользователя (`user`)
  - Функции CRUD: `addWorkout`, `updateWorkout`, `deleteWorkout`, `addShoe`, `updateUser`
  - Период фильтрации статистики (`period`) и функция `filterByPeriod`
- Контекст оборачивает всё приложение в `main.jsx`, поэтому данные доступны на любой странице без проброса пропсов через промежуточные компоненты.
- Для доступа к контексту используется кастомный хук `useApp()`.

### Интерфейс и навигация
- **Многостраничная навигация** с помощью `react-router-dom`:
  - Главная (`/`) — трекер тренировок и обуви
  - Статистика (`/statistics`) — страница с графиками и аналитикой (в разработке)
  - Профиль (`/profile`) — расширенная информация о пользователе (в разработке)
- Кнопка «+» рядом с заголовками «Тренировки», «Моя обувь», «Ближайшее соревнование» (добавление тренировки / обуви / соревнования)
- Убрана большая кнопка «Добавить тренировку» — заменена на компактный плюс
- Адаптивный дизайн, сине-серебристая гамма
- Сохранение данных в `localStorage` (тренировки, обувь, пользователь)
- **Компактные отступы** для оптимального использования экранного пространства

### Прочее
- Компонент `StatsPanel` отображает общее количество тренировок и дистанцию (пока без фильтрации по периодам)
- Рекорды (5 км, 10 км, полумарафон, марафон) — статические (будут вычисляться позже)
- Блок «Рекомендуемая обувь» — статический, с карточками и ссылками на магазины

## Стек технологий
- React (функциональные компоненты, хуки `useState`, `useEffect`, `createContext`, `useContext`)
- React Router v6 (маршрутизация)
- Vite (сборка)
- CSS (единый файл `App.css`, стили группированы по компонентам)

## Данные
- **Тренировки** хранятся в `localStorage` под ключом `rundefull_workouts`
- **Обувь** — `rundefull_shoes`
- **Пользователь** — `rundefull_user`
- Начальные данные импортируются из `src/data/initialData.js`

## Что не реализовано (планы)
- Фильтрация статистики по периодам (неделя/месяц/год) в `StatsPanel`
- Автоматический расчёт рекордов из тренировок (пока статика)
- Настоящие карты и графики (сейчас заглушки)
- Уведомления о превышении ресурса обуви
