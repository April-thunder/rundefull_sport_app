# RUNDEFULL — беговой трекер

Приложение на React для учёта тренировок, отслеживания ресурса обуви и анализа беговой статистики.

## Возможности

### Тренировки
- CRUD, пагинация (по 3), сортировка (новые сверху).
- Детальное окно с картой, графиками темпа/пульса (заглушки), кнопками редактирования и удаления.
- Дата в ISO, при показе форматируется (`16 апр 2025`); старые данные мигрируются автоматически.

### Обувь
- Список «Моя обувь» из `localStorage`.
- Добавление: выбор бренда (5), модели из 10 или ручной ввод, максимальный пробег; картинка подставляется по пути `/shoes/бренд-модель.webp`, заглушка при отсутствии.
- Индикатор ресурса: зелёный (<60%), жёлтый (60–90%), красный (≥90%).
- Пробег обуви обновляется при добавлении/редактировании/удалении тренировок.

### Статистика
- Страница `/statistics` с графиками (`recharts`):
  - объём (столбцы) с группировкой по годам/месяцам/неделям/дням;
  - средний темп (линия);
  - распределение по дистанциям (круговая);
  - пробег по обуви (круговая).
- Карточки метрик (общий пробег, кол-во, средний темп, средняя дистанция).
- На главной `StatsPanel` с выбором периода (Неделя, Месяц, Год, Всё время) — цифры обновляются.

### Профиль и авторизация
- Страница `/profile`:
  - редактирование имени, возраста, веса (валидация через `react-hook-form`);
  - загрузка/удаление фото (превью, base64 в `localStorage`);
  - кнопка выхода с подтверждением.
- На главной фото и данные пользователя (без кнопок редактирования).
- Имитация входа/выхода: флаг `isAuthenticated` в контексте, страница `/login` (любые данные → успешный вход). Защищённые маршруты через `PrivateRoute`.

### Интерфейс и навигация
- Роутинг (`react-router-dom`): `/`, `/statistics`, `/profile`, `/login`.
- Кнопки «+» для добавления тренировок, обуви, соревнований (вместо больших кнопок).
- Адаптивный дизайн, компактные отступы.
- Логотип — ссылка на главную.

## Стек
- React (хуки, Context API, кастомные хуки)
- React Router v6
- Vite
- CSS (единый файл)
- `recharts` (графики)
- `react-hook-form` + `react-hot-toast` (профиль)
- ESLint

## Данные
- Хранятся в `localStorage` под ключами `rundefull_workouts`, `rundefull_shoes`, `rundefull_user`, `rundefull_auth`.
- Начальные данные из `src/data/initialData.js`.
- Миграция дат из русского формата в ISO.

## Что не реализовано
- Расчёт рекордов из тренировок (сейчас статика).
- Настоящие карты и графики (заглушки).
- Уведомления об износе обуви.
- CRUD для соревнований.
- Импорт/экспорт данных (CSV).
- Настоящий бэкенд с авторизацией (сейчас имитация).
